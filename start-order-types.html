FXの始め方　I-5

FXの注文方法｜成行・指値・逆指値の使い分け

注文の種類は多く見えますが、覚えるべきは3つだけです。成行・指値・逆指値。残りはこの3つの組み合わせにすぎません。

この記事の要点

  • 損切りに使うのは逆指値。これを覚えないまま取引を始めない
  • OCOは利確と損切りを同時に置く形、IFDは新規と決済をセットで出す形

01覚えるのは3つだけ

注文方法は、値段を指定するかどうかと、どちら方向に指定するかで分かれます。

注文内容主な使いどころ
成行値段を指定せず、今のレートですぐ売買するすぐ入りたい・すぐ決済したい場面
指値「これ以下で買う／これ以上で売る」と有利な方向に指定押し目や戻りを待って入る場面
逆指値「これ以上で買う／これ以下で売る」と不利な方向に指定損切り、ブレイクを狙った新規

「不利な方向に指定する」という逆指値の考え方が、最初はつかみにくいところです。次の章で扱います。

02なぜ損切りに逆指値を使うのですか？

損切りとは、自分にとって不利な価格まで動いたら決済するという注文だからです。

150円で買ったポジションを149.50円で切りたいとします。これは「今より安い値段で売る」という注文なので、有利な方向に指定する指値では出せません。逆指値を使います。

逆指値を置いておけば、画面を見ていない間に相場が動いても自動で決済されます。見ていられないときほど必要になる注文です。

逆指値を覚える前に取引を始めないでください。損切り注文を置けないまま入ると、下がったときに「戻るかもしれない」と考えてしまい、損失が膨らみやすくなります。

03OCOとIFDは何が違いますか？

どちらも、3つの基本注文を組み合わせたものです。

OCO注文

2つの注文を同時に出し、片方が約定したらもう片方が自動でキャンセルされる形です。保有中のポジションに対して、利益確定の指値と損切りの逆指値を同時に置く使い方が一般的です。

IFD注文

新規注文と、それが約定したあとの決済注文をあらかじめセットで出しておく形です。「149円まで下がったら買い、151円になったら売る」といった予約ができます。

IFO注文

IFDとOCOを組み合わせたものです。新規・利確・損切りの3つを一度に予約できるため、入る前にすべてを決めておきたいときに使われます。

04スリッページに注意する

注文した値段と、実際に約定した値段はズレることがあります。これをスリッページと呼びます。

成行注文は「必ず約定する」代わりに、値段は保証されません。相場が急に動いている場面では、想定より不利な値段で約定することがあります。

とくに経済指標の発表直後は、数十pips単位でズレることもあります。損切りの逆指値も例外ではなく、置いた価格ぴったりで切れるとは限りません。

多くのFX会社では、許容できるスリッページの幅を設定できます。設定方法や挙動は会社ごとに違うため、デモ口座で確かめてから本番に進むのが安全です。

05よくある質問

指値と逆指値の違いは何ですか？

値段を指定する方向が逆です。指値は「これ以下で買う／これ以上で売る」と自分に有利な方向、逆指値は「これ以上で買う／これ以下で売る」と不利な方向に指定します。損切りに使うのは逆指値のほうです。

損切り注文はどの注文方法で出しますか？

逆指値です。損切りは今より不利な価格で決済する注文なので、有利な方向にしか指定できない指値では出せません。逆指値を置いておけば、画面を見ていない間に相場が動いても自動で決済されます。

成行注文なら必ず希望の値段で約定しますか？

しません。成行は約定することは保証されますが、値段は保証されません。相場が急に動いている場面では、注文時のレートと実際の約定レートがずれることがあり、これをスリッページと呼びます。
