# FX学習ノート

米ドル/円のデイトレード・短期トレードを対象に、テクニカル分析とファンダメンタルズ分析を基礎から上級まで4部構成で整理した学習サイトです。

**公開URL:** `https://<ユーザー名>.github.io/<リポジトリ名>/`

---

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ(4編への目次) |
| `basics.html` | **基礎編** — 2つの分析の役割分担、通貨ペアの選び方、主要指標の過去の値動き検証、目標設定 |
| `intro.html` | **入門編** — 学習ロードマップ(全6ステップ)、図解レッスン6本、練習問題6問、チェックリスト18項目 |
| `lines.html` | **実践編 Vol.2** — 「線」の意味。トレンドライン、ロールリバーサル、フィボナッチ、損切り位置 |
| `structure.html` | **上級編 Vol.3** — 相場の構造。MTF分析、4局面、流動性、期待値の数学、執行の技術 |

---

## 技術的な特徴

- **完全に自己完結**: 外部のCSS・JavaScript・画像を一切読み込みません。CDNもフォントの外部読み込みもゼロ。ファイルを置くだけで動きます
- **図はすべてインラインSVG**: ローソク足を生成するコードで描画しており、RSI・一目均衡表・ボリンジャーバンドは実際に計算した値を使用しています
- **ライト/ダーク両対応**: OSの設定に追従し、各ページ右上のボタンで手動切り替えもできます
- **レスポンシブ**: スマートフォン(横幅390px)でも横スクロールが発生しません
- **練習問題とチェックリストはページ内で動作**: 解答の判定・スコア表示・進捗バーはすべてクライアント側で完結します(状態はページを閉じるとリセットされます)

## 公開手順(GitHub Pages / ブラウザのみ)

1. GitHub で新しいリポジトリを作成する
   - **Public** を選ぶ(無料アカウントでは Private だと Pages を公開できません)
   - 「Add a README file」などのチェックはすべて**外したまま**にする
2. **Add file → Upload files** を開き、このフォルダの中のファイルを**すべて選んでドラッグ&ドロップ**する
   - フォルダごとではなく、**ファイル単体をまとめて**入れること(階層が深くなると404になります)
3. 下の **Commit changes** を押す
4. **Settings → Pages** を開く
5. **Source** を `Deploy from a branch`、**Branch** を `main` / `/ (root)` にして **Save**
6. 1〜2分待つと、ページ上部に表示されるURLで公開されます

※ ファイルのアップロードはPCのブラウザで行ってください。スマートフォンのブラウザでは操作できないことがあります。

## 更新のしかた(ブラウザのみ)

- **文章を直す**: リポジトリでファイル名をクリック → 右上の鉛筆アイコン → 編集 → **Commit changes**
- **ファイルごと差し替える**: **Add file → Upload files** で同じファイル名のものを入れると上書きされます

どちらの場合も、1分ほどで自動的にサイトへ反映されます。
