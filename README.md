# FX学習ノート

米ドル/円のデイトレード・短期トレードを対象に、**FXをまったく知らない状態から中級者になるまでを、順を追って学べる学習サイト**です。

すべての解説に図がついています。むずかしい概念もたとえ話に置き換えているので、チャートを開いたことがない段階からでも読み進められます。

**▶ サイトを開く: https://red-spider-lily-616.github.io/chart_school/**

---

## このサイトについて

FXの学習でつまずきやすいのは、知識が足りないことよりも **「覚えた指標をどう使えばいいのか分からない」** ことです。

そこでこのサイトは、指標のカタログではなく **「なぜそれが機能するのか」** を軸に構成しています。たとえばトレンドライン、水平線、移動平均線、フィボナッチ ― これらはすべて「その価格に注文が置かれているから効く」という一つの原理で説明できます。原理が分かれば、どの線を信じ、どの線を捨てるかを自分で判断できるようになります。

こんな人に向いています。

- FXを始めたばかりで、何からどの順に学べばいいか分からない
- 指標の名前は知っているが、実際の売買判断に結びついていない
- 「なんとなく」ではなく、毎回同じ基準で判断できるようになりたい

## 使える機能

- **練習問題** — 選択肢を選ぶとその場で正誤と解説が表示され、まちがえた項目の該当セクションへ戻れます
- **チェックリスト** — 各コース・各編の最後にあります。チェックを入れると進捗バーが動きます(ページを閉じるとリセットされるので、長期管理はノートに書き写してください)
- **ライト / ダークモード** — OSの設定に自動で追従します。各ページ上部の「表示切替」ボタンで手動切り替えもできます
- **スマートフォン対応** — 移動中でも図が崩れずに読めます

## 図について

掲載しているチャート図は、すべて **ローソク足を生成するコードで描いた模式図**です。実際の相場データではありません。

ただし指標の値は本物です。RSI・一目均衡表・ボリンジャーバンドは生成した価格データから実際に計算しているため、たとえばダイバージェンスの図では価格が高値を更新する一方でRSIが確かに切り下がっています。教材用に都合よく描いた線ではありません。
